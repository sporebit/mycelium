  - **Discriminator = the area, not a per-ticket flag.** `0116` already ships `areas` + `projects.area_id`. Technical-ness is a property of the project, so Tickets = tickets whose project sits under a technical area, Tasks = the rest.   - **Per-project keys are now a BLOCKER, not a follow-up.** `projects.prefix` exists (unique per space, `^[A-Z][A-Z0-9]{1,4}$`) but the key trigger still stamps the space prefix, so everything is `MYC-`. Harvesting other projects' backlogs before the trigger is fixed gives DropShipAuto and Polysnipe tickets `MYC-` keys, and keys are **stable on move** — permanent mislabelling on exactly the content being imported. Fix the trigger, then import.
  - **Sprints are new schema and pull against the Now view.** The spec chose GTD categories + the FROZEN NOW score ("what can I do here, now"); a sprint is "what did I commit to this iteration" — needs a `sprints` table (project, name, dates), membership, a commitment moment, and burndown/velocity off the existing Fibonacci points. Decide whether a sprint **is** the Doing set for technical projects or sits alongside Next/Doing; if both, there are two competing answers to "what am I working on".
