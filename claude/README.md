# claude/ — project docs mirror

These files mirror the Claude project's documents for Mycelium (instructions,
context, backlog, specs, decision records), imported 2026-09-15 so that Claude
Code sessions can read the specs the build prompts reference.

Two copies exist: the Claude project holds the working copy that Cowork
sessions edit; this folder is the repo copy. Until Tickets Part H makes the
backlog a generated export, treat the Claude project's copy as the one to
edit and re-import here when it changes.

The repo remains ground truth for code: when a doc here disagrees with the
code, the code wins and the doc is corrected.
